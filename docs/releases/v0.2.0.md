packwing 0.2.0 opens archives from Finder, draws scroll bars on its long lists and texts, and installs with Homebrew.

- **Open With on macOS:** Finder offers Packwing in Open With for the archives it opens, split archives' first parts too. An archive opened there, or dropped on Packwing's icon in the Dock, opens in packwing's window, the one already open if it runs. A double click still opens what it opened before: packwing takes it only for an archive nothing else opens.
- **Scroll bars:** an archive's list, a folder's, a storage's, Recent, the list of storages and the viewer's list of files show a scroll bar along their panel's edge when they are longer than it, and so do the texts in the preview and the viewer. Drag it, or press beside its thumb to go there.
- **Homebrew:** `brew install hivepaas/tap/pkw` installs the command line on macOS and Linux, and `brew install --cask hivepaas/tap/packwing` the app on macOS. `brew upgrade` keeps `pkw` up to date; the app updates itself, as it does from the disk image.
