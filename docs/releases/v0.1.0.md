The first release of packwing, a file archiver for macOS, Windows and Linux that opens archives safely.

- **Safe by default:** nothing is written outside the destination folder or through links, archive bombs stop at a size limit, and an existing file is never written over unless you say so.
- **Opens what you come across:** ZIP (split archives too), RAR 1.4 to 7, 7z, tar, cpio, ISO 9660 and UDF images, RPM and macOS packages, inside gzip, zstd, xz, bzip2 and more.
- **Writes archives:** ZIP, 7z, `.tar.gz`, `.tar.xz` and `.tar.zst`, with AES-256 on ZIP and 7z, and parts as 7-Zip cuts them. `.age` files too.
- **Edits ZIP archives**, searches and previews before extracting, and browses folders, S3 buckets, WebDAV folders and SFTP servers.
- **Signs files and checks checksums**, and works in the background, with a Jobs page.
- **In your file manager:** Compress and Extract in the right-click menu of Finder (its own menu), Windows Explorer and Nautilus, Dolphin, Nemo and Thunar.
- **`pkw`**, the command line, in every package, and on its own for servers and scripts.
- **Updates you can trust**, in a signed list, and policies for organizations.
