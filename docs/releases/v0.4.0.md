packwing 0.4.0 opens disk images and Windows images down to the files inside them, reads a self-extracting `.exe` as the archive it carries, gives light and dark styles of their own, and tells a screen reader what every control is.

- **Disk images, down to the files:** a card's `.img`, an Android ROM's sparse image (`super.img`), a `.vhd`, a `.vhdx` (Hyper-V's and WSL2's), a `.qcow2`, a `.vmdk` or VirtualBox's `.vdi` opens to the partitions its table names, **each partition a folder** named by its number and what it holds (`1-EFI`, `2-ext4`, `1-exfat`), with the files of its FAT, exFAT, ext or NTFS file system under it. A partition whose file system packwing does not read is one file of its bytes (`3-swap.img`), so it can still be taken off the disk; a disk with no table is one file system over its whole length, as WSL2's `ext4.vhdx` is. Read only: packwing writes no disk image and changes none. NTFS files that Windows compressed or encrypted, and its reparse points, are refused rather than written wrongly.
- **Windows images, each image a folder:** `install.wim` and `boot.wim` from a Windows disc, and what DISM, wimlib and 7-Zip write, open to the images the archive holds, **each image a folder** named by its number and the name the archive gives it (`1-Windows 11 Pro`, `2-Windows 11 Home`) — the number DISM's `/Index:` counts by — with its files under it; an archive of one image is that tree with no folder in front of it. The names an image says share a file come out as **hard links**, which a Windows image is full of, so an installation comes out once rather than a dozen times over, and **every file is held to the SHA-1 the image names it by**, which is the only check a WIM carries. A reparse point, a file whose data is in a solid block or compressed with LZMS (what an `.esd` from Windows Update holds), and one part of a split image (`.swm`) are refused and say why: what cannot come out whole does not come out.
- **Self-extracting archives:** a `.exe` that unpacks itself opens as the ZIP, 7z or RAR it holds, read from after the program. The program itself is never run.
- **Light and dark in styles:** seven styles for light and nine for dark, in Settings › General, changing the page, the cards, the fields and the lines; the defaults are the palettes as they were, to the value.
- **A screen reader is told:** every desktop control says what it is, its name and whether it is on, chosen or open — buttons, switches, check boxes, option cards, segments, menus and the select — over AT-SPI, UI Automation and NSAccessibility, so VoiceOver, Narrator and Orca read the window instead of one empty frame. A password field says it is one and never says what it holds.
- **Pro by subscription in the Mac App Store:** a month or a year, in place of the one-time purchase there. packwing is Pro while a subscription is current, and Free once it ends. The license bought outright is unchanged everywhere else.

Disk images and Windows images are in the right-click menu and Open With for the names they are known by, and `pkw list`, `pkw extract` and `pkw test` open them as they open any archive.
