packwing 0.3.0 reads the checksums of an archive's files and compares them with a list, signs in to SFTP servers with a key it keeps, and is on the Mac App Store.

- **Checksums of an archive's files:** the Archive page's `…` › Checksums… asks what to read: what is selected, all of the archive's files, or the archive itself. Its files are read in one pass, even for tar.gz, solid 7z and RAR, and each is named as extracting puts it. Copy one, copy them all as `sha256sum` writes them, or save the list beside the archive. **Compare…** takes a `SHA256SUMS` or BSD-style list pasted, and marks each file as matching, differing or not in the list. On the command line, `pkw checksum --in a.zip`.
- **SFTP asks in the window:** a server packwing has not met shows its key's fingerprint and is trusted only when you say so; a server whose key changed is refused. Passwords, key passphrases and the server's questions are asked in the window, and a password or passphrase is kept in the system's keychain only when you tick it. A storage can sign in with a key file you add, kept in the keychain, or with any key, as before.
- **The Mac App Store:** packwing is there too, in the App Sandbox. It extracts and compresses from Finder's right-click menu under Quick Actions or Services (Settings › Right-click menu says how to turn each item on or off), and Pro is bought in the app. It has no `pkw`, and the App Store updates it.
